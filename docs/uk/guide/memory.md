# Пам'ять

У кожного агента своя довготривала пам'ять. Завдяки їй агент продовжує розмову з того місця, де ви зупинилися, навіть після того як чат закрито.

## Що запам'ятовується

Спогад це коротке самодостатнє твердження з типом і важливістю від 0 до 1:

| Тип | Приклад |
| --- | --- |
| `fact` | База даних проєкту: Postgres 16 |
| `decision` | Вирішили тримати один файл SQLite на воркспейс |
| `preference` | Валя любить короткі відповіді з кодом |

Спогади з'являються трьома способами:

- Агент викликає інструмент `remember`, коли ти кажеш щось, що варто зберегти.
- Після кожного ходу фонова задача просить модель виділити з діалогу довгоживучі факти.
- Ти додаєш їх сам: у вкладці «Пам'ять», командою `crew memory add` або через API.

Якщо новий спогад майже збігається з наявним (косинусна близькість 0.9 і вище), його пропускають.

## Як працює пошук

Пошук іде просто в SQLite і поєднує два методи:

1. Повнотекстовий індекс (FTS5) з ранжуванням BM25.
2. Ембединги з твоєї моделі ембедингів (за замовчуванням `nomic-embed-text`). Вони зберігаються як blob і порівнюються за косинусною близькістю.

Два рейтинги об'єднуються через reciprocal-rank fusion і трохи коригуються за важливістю та віком.

Якщо моделі ембедингів немає, Crew переходить на повнотекстовий пошук, а ембединги дорахує пізніше.

Спогади з важливістю 0.8 і вище вважаються ключовими й завжди потрапляють у контекст агента.

## Перегляд і правка

```bash
crew memory Lena                     # список
crew memory Lena --search "стек"     # пошук
crew memory add Lena "Реліз у п'ятницю" --type decision
```

У веб-інтерфейсі відкрий агента й перейди у вкладку «Пам'ять»: там можна шукати, додавати й видаляти.

::: tip
Очищення чату пам'ять не стирає.
:::
