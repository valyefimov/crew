# Пам'ять

У кожного агента своя довготривала пам'ять. Саме вона робить агента в Crew *колегою*, а не вікном чату.

## Що запам'ятовується

Спогад — коротке самодостатнє твердження з типом і важливістю від 0 до 1:

| Тип | Приклад |
| --- | --- |
| `fact` | База даних проєкту — Postgres 16 |
| `decision` | Вирішили тримати один файл SQLite на воркспейс |
| `preference` | Валя любить короткі відповіді з кодом |

Спогади з'являються трьома шляхами:

- **Сам агент** — викликає інструмент `remember`, коли ти кажеш щось важливе.
- **Автоматично** — після кожного ходу фонова задача просить модель виділити довготривалі факти.
- **Ти сам** — у вкладці «Пам'ять», через `crew memory add` або через API.

Майже-дублікати пропускаються (косинусна близькість ≥ 0.9 з наявним спогадом).

## Як працює пошук

Crew використовує гібридний пошук просто в SQLite:

1. **Повнотекстовий** — індекс FTS5 з ранжуванням BM25.
2. **Векторний** — ембединги з моделі ембедингів (за замовчуванням `nomic-embed-text`) зберігаються як blob і порівнюються за косинусом.
3. Обидва рейтинги об'єднуються через reciprocal-rank fusion і коригуються за важливістю та свіжістю.

Якщо моделі ембедингів немає, Crew тихо переходить на повнотекстовий пошук, а ембединги догенерує пізніше.

Спогади з важливістю ≥ 0.8 — *ключові*: вони завжди в контексті агента.

## Перегляд і редагування

```bash
crew memory Lena                     # список
crew memory Lena --search "стек"     # пошук
crew memory add Lena "Реліз у п'ятницю" --type decision
```

У веб-інтерфейсі: відкрий агента → **Пам'ять** — пошук, додавання й видалення.

::: tip
Очищення чату не стирає пам'ять. У цьому весь сенс.
:::
