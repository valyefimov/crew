# Файли

Агенти можуть працювати з твоїми файлами, але лише в тих теках, які ти їм відкрив.

```bash
crew agent grant Artem ~/code/my-api          # лише читання
crew agent grant Sofia ~/notes/blog --rw      # читання і запис
```

У веб-інтерфейсі відкрий агента, перейди у вкладку «Файли» й додай абсолютний шлях.

## Інструменти

Коли відкрита хоча б одна тека, агент отримує три інструменти:

| Інструмент | Що робить |
| --- | --- |
| `list_files` | Показує вміст теки. Приховані файли й `node_modules` пропускає. |
| `read_file` | Читає текстовий файл, до 64 КБ. Бінарні файли розпізнає й не читає. |
| `write_file` | Створює або перезаписує файл. Працює лише в теках `rw`. |

Відносні шляхи рахуються від відкритих тек, тому «прочитай package.json» працює так, як очікуєш.

## Безпека

Кожен шлях проходить через `realpath` до перевірки прав, тому `../` і симлінки не виведуть агента за межі відкритої теки. Новий файл перевіряється через найближчу наявну батьківську теку. Для запису тека має бути відкрита як `rw`.

Виклики інструментів видно в чаті маленькими плашками, тож завжди зрозуміло, що чіпав агент.
