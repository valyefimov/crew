# Файли

Агенти вміють працювати з твоїми файлами — але лише в тих теках, які ти явно відкрив.

```bash
crew agent grant Artem ~/code/my-api          # лише читання
crew agent grant Sofia ~/notes/blog --rw      # читання і запис
```

Або у веб-інтерфейсі: відкрий агента → **Файли** → додай абсолютний шлях.

## Інструменти

Коли відкрита хоча б одна тека, агент отримує три інструменти:

| Інструмент | Що робить |
| --- | --- |
| `list_files` | Показує вміст теки (приховані файли й `node_modules` пропускаються) |
| `read_file` | Читає текстовий файл (до 64 КБ; бінарні файли розпізнаються) |
| `write_file` | Створює або перезаписує файл — лише в теках `rw` |

Відносні шляхи рахуються від відкритих тек, тож *«прочитай package.json»* просто працює.

## Безпека

- Кожен шлях спершу розв'язується через `realpath`, і лише **потім** перевіряється — `../` і симлінки не випустять за межі теки.
- Нові файли перевіряються через найближчу наявну батьківську теку.
- Для запису тека має бути відкрита як `rw`.

Виклики інструментів видно в чаті плашками — ти завжди бачиш, що чіпав агент.
