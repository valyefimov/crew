# Агенти

Агент це постійний колега. У нього є ім'я, роль, характер, необов'язкові інструкції, а також своя пам'ять і свої теки.

| Поле | Навіщо потрібне |
| --- | --- |
| `name` | Унікальне, регістр не важливий. Використовується скрізь: `crew chat Lena`, `/use Lena` у Telegram. |
| `role` | Один рядок, наприклад «Senior backend engineer». Потрапляє в системний промпт. |
| `personality` | Як агент говорить і поводиться. |
| `systemPrompt` | Додаткові інструкції: з чим йому допомагати. |
| `model` | Необов'язкова модель для цього агента. Порожньо означає глобальну за замовчуванням. |
| `avatar` | Будь-який емодзі. |

## Шаблони

| Шаблон | Агент |
| --- | --- |
| `backend` | Artem, senior backend-розробник |
| `frontend` | Lena, фронтенд-розробниця й дизайнерка |
| `pm` | Max, продакт-менеджер |
| `writer` | Sofia, авторка й редакторка |
| `coach` | Oleg, особистий коуч |

```bash
crew agent create Lena --template frontend
crew agent create Kate --role "Аналітик даних" --persona "Допитлива, обожнює графіки" --model qwen2.5:7b
```

## Як відбувається хід

1. Crew зберігає твоє повідомлення.
2. Знаходить найвідповідніші спогади, додає найважливіші й збирає системний промпт.
3. Модель відповідає й по ходу може викликати інструменти: `remember`, `recall` та файлові, якщо відкрита тека. За один хід допускається до 6 раундів викликів.
4. Відповідь стримиться в усі підключені клієнти й зберігається.
5. Фонова задача перечитує діалог і витягує нові довготривалі спогади.

Ходи одного агента виконуються по черзі, тому повідомлення з вебу, CLI та Telegram не перемішуються.

## Статуси

Агенти повідомляють, чим зайняті, в реальному часі: `idle`, `thinking`, `working` (виконує інструмент) і `remembering` (витягує спогади). На дашборді видно всю команду одразу.

## Експорт та імпорт

```bash
crew agent export Lena            # → Lena.crew.json, разом із пам'яттю
crew agent import Lena.crew.json
```

Те саме є у веб-інтерфейсі: у профілі кнопка «Експорт», у вікні «Новий колега» кнопка «Імпорт».
