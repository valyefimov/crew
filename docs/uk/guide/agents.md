# Агенти

Агент — це постійний колега: ім'я, роль, характер, інструкції, а також своя пам'ять і свої теки.

| Поле | Навіщо |
| --- | --- |
| `name` | Унікальне, без урахування регістру. Використовується всюди: `crew chat Lena`, `/use Lena` у Telegram. |
| `role` | Один рядок, наприклад *Senior backend engineer*. Потрапляє в системний промпт. |
| `personality` | Як агент говорить і поводиться. |
| `systemPrompt` | Додаткові інструкції — з чим допомагати. |
| `model` | Власна модель агента. Порожньо — глобальна за замовчуванням. |
| `avatar` | Будь-який емодзі. |

## Шаблони

| Шаблон | Агент |
| --- | --- |
| `backend` | 🛠️ Artem — senior backend-розробник |

```bash
crew agent create Lena --template frontend
crew agent create Kate --role "Аналітик даних" --persona "Допитлива, обожнює графіки" --model qwen2.5:7b
```

## Як відбувається хід

1. Crew зберігає твоє повідомлення.
2. Дістає найрелевантніші спогади (плюс найважливіші) і збирає системний промпт.
3. Модель відповідає й може викликати інструменти — `remember`, `recall` і файлові, якщо відкриті теки. До 6 раундів інструментів за хід.
4. Відповідь стримиться в усі підключені клієнти й зберігається.
5. Фонова задача перечитує діалог і витягує нові довготривалі спогади.

Ходи одного агента виконуються по черзі, тому повідомлення з вебу, CLI та Telegram ніколи не перемішуються.

## Статуси

Агенти в реальному часі показують, чим зайняті: `idle`, `thinking`, `working` (виконує інструмент) і `remembering` (витягує спогади). На дашборді видно всю команду.

## Експорт та імпорт

```bash
crew agent export Lena            # → Lena.crew.json, разом із пам'яттю
crew agent import Lena.crew.json
```

Те саме є у веб-інтерфейсі (Профіль → Експорт, Новий колега → Імпорт).
