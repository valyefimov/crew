# Telegram

Спілкуйся зі своєю командою з телефона.

## Налаштування

1. Створи бота через [@BotFather](https://t.me/BotFather) і скопіюй токен.
2. Передай його Crew — у **Налаштування → Токен Telegram-бота** або так:

```bash
crew config set telegramToken 123456:ABC-DEF...
# або: CREW_TELEGRAM_TOKEN=... crew start
```

3. Перезапусти Crew. У терміналі з'явиться код сполучення:

```
✔ Telegram bot online — send /pair 482913 to it
```

4. Надішли боту `/pair 482913`. Спілкуватися з командою можуть лише сполучені чати.

## Команди

| Команда | |
| --- | --- |
| `/agents` | Список колег, ▶️ — поточний |
| `/use Lena` | Перемкнутися на іншого агента |
| `/memory` | Що пам'ятає поточний агент |
| `/forget` | Очистити історію цього чату (пам'ять лишається) |

Можна звернутися до когось просто в повідомленні: `Lena, як тобі ця кнопка?`

У Telegram своє листування на кожен чат, але **пам'ять спільна** — розкажи Лєні щось у Telegram, і вона знатиме це й у веб-інтерфейсі.
