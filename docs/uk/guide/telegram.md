# Telegram

З командою можна спілкуватися з телефона.

## Налаштування

1. Створи бота через [@BotFather](https://t.me/BotFather) і скопіюй токен.
2. Передай токен Crew: у налаштуваннях (поле «Токен Telegram-бота») або так:

```bash
crew config set telegramToken 123456:ABC-DEF...
# або: CREW_TELEGRAM_TOKEN=... crew start
```

3. Перезапусти Crew. У терміналі з'явиться код сполучення:

```
✔ Telegram bot online — send /pair 482913 to it
```

4. Надішли боту `/pair 482913`. Спілкуватися з командою зможуть лише сполучені чати.

## Команди

| Команда | Що робить |
| --- | --- |
| `/agents` | Показує агентів. ▶️ позначає поточного. |
| `/use Lena` | Перемикає, з ким ти говориш. |
| `/memory` | Показує, що пам'ятає поточний агент. |
| `/forget` | Очищає історію цього чату. Пам'ять лишається. |

До агента можна звернутися й просто в повідомленні: `Lena, як тобі ця кнопка?`

У кожного чату в Telegram своя історія листування, а пам'ять спільна з веб-інтерфейсом. Розкажи Лєні щось у Telegram, і вона знатиме це й у браузері.
