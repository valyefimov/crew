# Roadmap

## v1.0 (released)

- [x] Multiple agents with a role and a personality
- [x] Long-term memory for each agent (FTS5 + vectors, automatic extraction)
- [x] Web UI: dashboard, chat, memory, files, profile
- [x] Local files in shared folders (ro / rw)
- [x] Ollama and OpenAI-compatible providers
- [x] CLI
- [x] Telegram bot with pairing
- [x] Background task queue
- [x] English, Russian and Ukrainian UI

## v1.1

- [ ] Local voice: Whisper.cpp for speech-to-text, Piper or Kokoro for text-to-speech
- [ ] Voice messages in Telegram
- [ ] Scheduled tasks ("every Friday, write release notes")
- [ ] Sandboxed command execution (Docker)

## v1.2

- [ ] Slack
- [ ] Multiple workspaces
- [ ] Agents talking to each other

## v2.0

- [ ] Team mode: several people sharing agents
- [ ] A marketplace of characters and skills
- [ ] PWA
- [ ] Plugins

Ideas and pull requests are welcome. [Open an issue](https://github.com/valyefimov/crew/issues).
