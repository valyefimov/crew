# Файлы

Агенты умеют работать с твоими файлами — но только в тех папках, которые ты явно открыл.

```bash
crew agent grant Artem ~/code/my-api          # только чтение
crew agent grant Sofia ~/notes/blog --rw      # чтение и запись
```

Или в веб-интерфейсе: открой агента → **Файлы** → добавь абсолютный путь.

## Инструменты

Когда открыта хотя бы одна папка, агент получает три инструмента:

| Инструмент | Что делает |
| --- | --- |
| `list_files` | Показывает содержимое папки (скрытые файлы и `node_modules` пропускаются) |
| `read_file` | Читает текстовый файл (до 64 КБ; бинарники распознаются) |
| `write_file` | Создаёт или перезаписывает файл — только в папках `rw` |

Относительные пути считаются от открытых папок, так что *«прочитай package.json»* просто работает.

## Безопасность

- Каждый путь сначала разрешается через `realpath`, и только **потом** проверяется — `../` и симлинки не выпустят за пределы папки.
- Новые файлы проверяются через ближайшую существующую родительскую папку.
- Для записи папка должна быть открыта как `rw`.

Вызовы инструментов видны в чате плашками — ты всегда видишь, что трогал агент.
