# Файлы

Агенты могут работать с твоими файлами, но только в тех папках, которые ты им открыл.

```bash
crew agent grant Artem ~/code/my-api          # только чтение
crew agent grant Sofia ~/notes/blog --rw      # чтение и запись
```

В веб-интерфейсе открой агента, перейди во вкладку «Файлы» и добавь абсолютный путь.

## Инструменты

Когда открыта хотя бы одна папка, агент получает три инструмента:

| Инструмент | Что делает |
| --- | --- |
| `list_files` | Показывает содержимое папки. Скрытые файлы и `node_modules` пропускает. |
| `read_file` | Читает текстовый файл, до 64 КБ. Бинарные файлы распознаёт и не читает. |
| `write_file` | Создаёт или перезаписывает файл. Работает только в папках `rw`. |

Относительные пути считаются от открытых папок, поэтому «прочитай package.json» работает так, как ожидаешь.

## Безопасность

Каждый путь проходит через `realpath` до проверки прав, поэтому `../` и симлинки не выведут агента за пределы открытой папки. Новый файл проверяется через ближайшую существующую родительскую папку. Для записи папка должна быть открыта как `rw`.

Вызовы инструментов видны в чате маленькими плашками, так что всегда понятно, что трогал агент.
