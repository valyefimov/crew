# Память

У каждого агента своя долговременная память. Благодаря ей агент продолжает разговор с того места, где вы остановились, даже после того как чат закрыт.

## Что запоминается

Воспоминание это короткое самодостаточное утверждение с типом и важностью от 0 до 1:

| Тип | Пример |
| --- | --- |
| `fact` | База данных проекта: Postgres 16 |
| `decision` | Решили держать один файл SQLite на воркспейс |
| `preference` | Валя любит короткие ответы с кодом |

Воспоминания появляются тремя способами:

- Агент вызывает инструмент `remember`, когда ты говоришь что-то, что стоит сохранить.
- После каждого хода фоновая задача просит модель выделить из диалога долгоживущие факты.
- Ты добавляешь их сам: во вкладке «Память», командой `crew memory add` или через API.

Если новое воспоминание почти совпадает с уже существующим (косинусная близость 0.9 и выше), оно пропускается.

## Как работает поиск

Поиск идёт прямо в SQLite и сочетает два метода:

1. Полнотекстовый индекс (FTS5) с ранжированием BM25.
2. Эмбеддинги из твоей модели эмбеддингов (по умолчанию `nomic-embed-text`). Они хранятся как blob и сравниваются по косинусной близости.

Два рейтинга объединяются через reciprocal-rank fusion и слегка корректируются по важности и возрасту.

Если модели эмбеддингов нет, Crew переходит на полнотекстовый поиск, а эмбеддинги досчитает позже.

Воспоминания с важностью 0.8 и выше считаются ключевыми и всегда попадают в контекст агента.

## Просмотр и правка

```bash
crew memory Lena                     # список
crew memory Lena --search "стек"     # поиск
crew memory add Lena "Релиз в пятницу" --type decision
```

В веб-интерфейсе открой агента и перейди во вкладку «Память»: там можно искать, добавлять и удалять.

::: tip
Очистка чата память не стирает.
:::
