# Память

У каждого агента своя долговременная память. Именно она делает агента в Crew *коллегой*, а не окном чата.

## Что запоминается

Воспоминание — короткое самодостаточное утверждение с типом и важностью от 0 до 1:

| Тип | Пример |
| --- | --- |
| `fact` | База данных проекта — Postgres 16 |
| `decision` | Решили держать один файл SQLite на воркспейс |
| `preference` | Валя любит короткие ответы с кодом |

Воспоминания появляются тремя путями:

- **Сам агент** — вызывает инструмент `remember`, когда ты говоришь что-то важное.
- **Автоматически** — после каждого хода фоновая задача просит модель выделить долгоживущие факты.
- **Ты сам** — во вкладке «Память», через `crew memory add` или через API.

Почти-дубликаты пропускаются (косинусная близость ≥ 0.9 с уже существующим воспоминанием).

## Как работает поиск

Crew использует гибридный поиск прямо в SQLite:

1. **Полнотекстовый** — индекс FTS5 с ранжированием BM25.
2. **Векторный** — эмбеддинги из модели эмбеддингов (по умолчанию `nomic-embed-text`) хранятся как blob и сравниваются по косинусу.
3. Оба рейтинга объединяются через reciprocal-rank fusion и корректируются по важности и свежести.

Если модели эмбеддингов нет, Crew тихо переключается на полнотекстовый поиск, а эмбеддинги догенерирует позже.

Воспоминания с важностью ≥ 0.8 — *ключевые*: они всегда в контексте агента.

## Просмотр и редактирование

```bash
crew memory Lena                     # список
crew memory Lena --search "стек"     # поиск
crew memory add Lena "Релиз в пятницу" --type decision
```

В веб-интерфейсе: открой агента → **Память** — поиск, добавление и удаление.

::: tip
Очистка чата не стирает память. В этом весь смысл.
:::
