# Агенты

Агент — это постоянный коллега: имя, роль, характер, инструкции, а также своя память и свои папки.

| Поле | Зачем |
| --- | --- |
| `name` | Уникальное, без учёта регистра. Используется везде: `crew chat Lena`, `/use Lena` в Telegram. |
| `role` | Одна строка, например *Senior backend engineer*. Попадает в системный промпт. |
| `personality` | Как агент говорит и ведёт себя. |
| `systemPrompt` | Дополнительные инструкции — с чем помогать. |
| `model` | Своя модель для агента. Пусто — глобальная по умолчанию. |
| `avatar` | Любой эмодзи. |

```bash
crew agent create Lena --template frontend
crew agent create Kate --role "Аналитик данных" --persona "Любопытная, обожает графики" --model qwen2.5:7b
```

## Как проходит ход

1. Crew сохраняет твоё сообщение.
2. Достаёт самые релевантные воспоминания (плюс самые важные) и собирает системный промпт.
3. Модель отвечает и может вызывать инструменты — `remember`, `recall` и файловые, если открыты папки. До 6 раундов инструментов за ход.
4. Ответ стримится во все подключённые клиенты и сохраняется.
5. Фоновая задача перечитывает диалог и извлекает новые долговременные воспоминания.

Ходы одного агента выполняются по очереди, поэтому сообщения из веба, CLI и Telegram никогда не перемешиваются.

## Статусы

Агенты в реальном времени показывают, чем заняты: `idle`, `thinking`, `working` (выполняет инструмент) и `remembering` (извлекает воспоминания). На дашборде видно всю команду.

## Экспорт и импорт

```bash
crew agent export Lena            # → Lena.crew.json, вместе с памятью
crew agent import Lena.crew.json
```

То же самое есть в веб-интерфейсе (Профиль → Экспорт, Новый коллега → Импорт).
