# Агенты

Агент это постоянный коллега. У него есть имя, роль, характер, необязательные инструкции, а также своя память и свои папки.

| Поле | Зачем нужно |
| --- | --- |
| `name` | Уникальное, регистр не важен. Используется везде: `crew chat Lena`, `/use Lena` в Telegram. |
| `role` | Одна строка, например «Senior backend engineer». Попадает в системный промпт. |
| `personality` | Как агент говорит и ведёт себя. |
| `systemPrompt` | Дополнительные инструкции: с чем ему помогать. |
| `model` | Необязательная модель для этого агента. Пусто значит глобальная по умолчанию. |
| `avatar` | Любой эмодзи. |

## Шаблоны

| Шаблон | Агент |
| --- | --- |
| `backend` | Artem, senior backend-разработчик |
| `frontend` | Lena, фронтенд-разработчик и дизайнер |
| `pm` | Max, продакт-менеджер |
| `writer` | Sofia, автор и редактор |
| `coach` | Oleg, личный коуч |

```bash
crew agent create Lena --template frontend
crew agent create Kate --role "Аналитик данных" --persona "Любопытная, обожает графики" --model qwen2.5:7b
```

## Как проходит ход

1. Crew сохраняет твоё сообщение.
2. Находит самые подходящие воспоминания, добавляет самые важные и собирает системный промпт.
3. Модель отвечает и по ходу может вызывать инструменты: `remember`, `recall` и файловые, если открыта папка. За один ход допускается до 6 раундов вызовов.
4. Ответ стримится во все подключённые клиенты и сохраняется.
5. Фоновая задача перечитывает диалог и извлекает новые долговременные воспоминания.

Ходы одного агента выполняются по очереди, поэтому сообщения из веба, CLI и Telegram не перемешиваются.

## Статусы

Агенты сообщают, чем заняты, в реальном времени: `idle`, `thinking`, `working` (выполняет инструмент) и `remembering` (извлекает воспоминания). На дашборде видна вся команда сразу.

## Экспорт и импорт

```bash
crew agent export Lena            # → Lena.crew.json, вместе с памятью
crew agent import Lena.crew.json
```

То же есть в веб-интерфейсе: в профиле кнопка «Экспорт», в окне «Новый коллега» кнопка «Импорт».
