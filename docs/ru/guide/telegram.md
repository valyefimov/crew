# Telegram

Общайся со своей командой с телефона.

## Настройка

1. Создай бота через [@BotFather](https://t.me/BotFather) и скопируй токен.
2. Передай его Crew — в **Настройки → Токен Telegram-бота** или так:

```bash
crew config set telegramToken 123456:ABC-DEF...
# или: CREW_TELEGRAM_TOKEN=... crew start
```

3. Перезапусти Crew. В терминале появится код сопряжения:

```
✔ Telegram bot online — send /pair 482913 to it
```

4. Отправь боту `/pair 482913`. Общаться с командой могут только сопряжённые чаты.

## Команды

| Команда | |
| --- | --- |
| `/agents` | Список коллег, ▶️ — текущий |
| `/use Lena` | Переключиться на другого агента |
| `/memory` | Что помнит текущий агент |
| `/forget` | Очистить историю этого чата (память остаётся) |

Можно обратиться к кому-то прямо в сообщении: `Lena, как тебе эта кнопка?`

У Telegram своя переписка на каждый чат, но **память общая** — расскажи Лене что-то в Telegram, и она будет знать это и в веб-интерфейсе.
