# Telegram

С командой можно общаться с телефона.

## Настройка

1. Создай бота через [@BotFather](https://t.me/BotFather) и скопируй токен.
2. Передай токен Crew: в настройках (поле «Токен Telegram-бота») или так:

```bash
crew config set telegramToken 123456:ABC-DEF...
# или: CREW_TELEGRAM_TOKEN=... crew start
```

3. Перезапусти Crew. В терминале появится код сопряжения:

```
✔ Telegram bot online — send /pair 482913 to it
```

4. Отправь боту `/pair 482913`. Общаться с командой смогут только сопряжённые чаты.

## Команды

| Команда | Что делает |
| --- | --- |
| `/agents` | Показывает агентов. ▶️ отмечает текущего. |
| `/use Lena` | Переключает, с кем ты говоришь. |
| `/memory` | Показывает, что помнит текущий агент. |
| `/forget` | Очищает историю этого чата. Память остаётся. |

К агенту можно обратиться и прямо в сообщении: `Lena, как тебе эта кнопка?`

У каждого чата в Telegram своя история переписки, а память общая с веб-интерфейсом. Расскажи Лене что-нибудь в Telegram, и она будет знать это и в браузере.
